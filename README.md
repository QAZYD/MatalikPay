# MatalikPay
 The project is an educational simulation that teaches the developer how might a fintech work in enterprise settings.  

 >**Disclaimer:** MatalikPay is an educational project and does not process
 >real financial transactions

## Overview
MatalikPay is a full-stack application designed to simulate core payment-system functionality, include user accounts,
authentication, payments, and transaction history.

The project is also intended to demonstrate professional software development practices such as testing, documentation,
CI, and version-controlled development.

## Features 
- [ ] User registration
- [ ] User authentication
- [ ] Account management
- [ ] Payment processing
- [ ] Transaction history
